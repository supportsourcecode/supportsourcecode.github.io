LUMENBOARD RUNNING INSTRUCTIONS

Prerequisite

Install Node.js version 22.13 or newer.

Check your installed versions in Command Prompt (CMD) or PowerShell:

node --version
npm --version

If double-clicking the icon does not start the local server, manually start the application from any drive (C:, D:, etc.) as follows:

  1. Install the application to your preferred path (for example, D:\Lumenboard Designer_1.0).
  2. Open Command Prompt (CMD) or PowerShell.
  3. Go to the resources\app folder inside the installed directory:
    cd "D:\Lumenboard Designer_1.0\resources\app"
  4. Start the server and keep this window open while you use Lumenboard:
    npm run dev
  5. Wait until the server reports that it is ready.
  6. Open your browser and navigate to http://localhost:3000 to use the application with full access.
  7. Close the Command Prompt or press Ctrl+C when you are finished.
